# 悬浮导航

[文档索引](README.md) · [安装与升级](INSTALL.md) · [验证记录](VALIDATION.md)

本文记录 0.6.0+7 开发版的交互约定；该版本正在准备构建与发布。已发布的 0.5.0 APK 不包含本次导航更新。自动测试、设备操作和未覆盖事项以对应提交的 [验证记录](VALIDATION.md) 为准。

## 开启与布局

入口为“设置 → 外观设置 → 悬浮底栏”，开关即时生效。0.6.0 默认启用，保留已有明确关闭的偏好；导航项仍由“导航栏编辑”控制顺序与隐藏状态。

底栏采用居中的胶囊外形，使用主题表面色、轮廓和柔和阴影。选中背景在胶囊内部移动，图标、标签及动态未读标记保持各自的命中区域。布局适配底部与左右系统安全区；横屏和平板沿用侧栏。

## 点击、拖动与停留

| 操作 | 页面行为 |
| --- | --- |
| 点击导航项，或通过键盘／辅助功能激活 | 直接选择对应页面；点击当前项沿用原有回顶／刷新行为 |
| 按住并拖动 | 选中背景连续跟手，页面保持原位置 |
| 在另一导航项停稳约 200 毫秒 | 切到该页一次；继续按住时还可拖向其他项 |
| 快速跨过一项，或未停稳就松手 | 取消该次待切换，背景回到实际选中的页面 |
| 拖出胶囊或取消手势 | 撤销尚未完成的停留，不补交切页 |

停留时间从最后一次有效移动开始计算；约 4dp 的累计抖动容差用于减少手指轻微抖动的影响。在同一项内继续移动也会重新计时，因此长时间拖过一个较宽的导航项不等于静止停留。松手不补交尚未完成的停留，已经完成的页面切换则保留。

多指操作、应用进入后台或失焦、外部切页、导航编辑，以及底栏隐藏或键盘显示时，均应终止待切换。切换悬浮样式保留当前页面与页面控制器；导航重排或隐藏项目时，沿用按页面身份保留选中的规则。

## 布局与验收边界

本轮需要覆盖明暗与动态主题色、两项／三项导航、窄屏、大字号、RTL、安全区、键盘焦点、已选语义和减少动画设置。胶囊周围的透明区域应保持内容触摸穿透。

这些是本轮的实现与验收范围，不能据此认定所有设备均已通过。尤其是 ARM64 真机、系统手势竞争、长时间运行和真实账号业务，需要同版本安装包另行验收；历史扫码、分享与播放证据不能代替本轮导航的设备结果。

## 设计参考

本项目参考了以下公开项目的视觉与交互原则，并独立实现 Pili-- 的导航部件：

- [TG-Twilight/c001apk 的 LiquidNavigationBar](https://github.com/TG-Twilight/c001apk/blob/8373ffe50a2bbf32420f0bffd45ded16bda75b65/apps/flutter/lib/components/basic_glass.dart#L176)：居中的胶囊形态、主题表面色和选中预览。该上游版本在松手时提交页面。
- [Ktclat/c001apk-native 的 NavigationTabDragSession](https://github.com/Ktclat/c001apk-native/blob/fdb177a89064e9f353665e3f6eacc18e3b128776/app/src/main/java/io/github/ktclat/c001apk/nativeapp/ui/NavigationTabDragSession.kt)：移动后重新计算静止停留，以及取消与失焦处理。Pili-- 采用未完成停留就松手时取消的交互。
