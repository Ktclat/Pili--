# 安装与升级

## 获取预发布测试包

最近的预发布版为 **0.6.0+7**，包含悬浮导航更新，使用 Actions 临时测试签名。首次稳定版仍待发行。[v0.6.0-beta.1 下载页](https://github.com/Ktclat/Pili--/releases/tag/v0.6.0-beta.1)

1. 打开上述 Release，在 **Assets** 中按下表下载一个 APK；不要把源码压缩包当作安装包。
2. 下载同页的 `SHA256SUMS.txt`，核对所选 APK 的 SHA-256。
3. `BUILD_INFO.json` 记录实际包身份、签名证书摘要及来源；`PiliMinus-0.6.0+7-source.tar.gz` 提供对应源码和构建材料。
4. 通过 Android 安装界面安装；按系统提示为使用的文件管理器或浏览器授予安装来源权限。

| APK | 适用设备 |
| --- | --- |
| `PiliMinus-0.6.0+7-arm64-v8a-test-signed.apk` | 多数当前 Android 手机，建议优先确认此架构 |
| `PiliMinus-0.6.0+7-armeabi-v7a-test-signed.apk` | 支持 32 位 ARM 的设备 |
| `PiliMinus-0.6.0+7-x86_64-test-signed.apk` | x86_64 Android 设备或模拟器 |

最低 Android 版本为 **7.0 / API 24**。不确定架构时可查看设备资料；开发者可运行 `adb shell getprop ro.product.cpu.abilist`。构建标为 `release` 仅指编译模式，CI 包仍使用测试签名。

**0.6.3+12** 的三个架构测试包包含最新的右上角按钮设置。公开的 +11 和 +12 Actions 包签名不同，Android 无法直接覆盖安装。已安装公开 +11 的用户如需换包，请先在「设置 → 关于」导出要保留的数据。[0.6.3+12 测试 APK](https://github.com/Ktclat/Pili--/actions/runs/45592612772/artifacts/15011943766) · [验证记录](VALIDATION.md)

开发测试包也可从成功的 [Android validation build](https://github.com/Ktclat/Pili--/actions/workflows/build.yml) 下载：选择目标提交，在 **Artifacts** 获取 `Pili--Android-test-signed` 并解压。Actions 附件需登录 GitHub，默认保留 14 天，其中 APK 使用 `app-<ABI>-release.apk` 命名；这项期限不适用于已上传的 Release 附件。取消或失败的运行不能视为已验证版本。

应用内检查更新只读取稳定 Release，会忽略本次 Pre-release；提示没有稳定发行版时，请从本页链接手动下载。预发布构建来源为提交 `8998b8fc8ee3edc649cebca05422cc78ca3e63b6` 和 [本次 Actions](https://github.com/Ktclat/Pili--/actions/runs/41070378254)。

## 与 PiliPlus 一起使用

Pili-- 使用 `io.github.ktclat.piliminus`，上游 PiliPlus 使用 `com.example.piliplus`。可以保留上游后安装本项目，账号、设置和默认离线目录各自独立，不自动导入上游账号。

两者可能同时接收 B 站通用链接，由系统默认打开方式决定。可在 Android 的“应用 → 默认打开方式”调整。共存实现与验证范围见 [COEXISTENCE.md](COEXISTENCE.md)。

## 扫码授权与链接识别

- 开发版的「扫一扫」默认在「我的 → 更多操作（⋮）」中，支持相机和相册。扫描内容码后可选择打开；扫描本人设备的网页或 TV 登录码后，核对账号与登录位置再确认授权。已发布的 0.6.0 仍有独立的「扫码授权登录」入口。
- 从 0.6.1 起支持其他 Android App 直接唤起授权页。对方能复制官方扫码登录链接时，也可在「扫一扫」点「粘贴登录链接」。授权后切回原 App 查看结果。[接入说明](INPUT_RECOGNITION.md)
- 「识别链接」默认在「我的 → 更多操作（⋮）」中。手动输入或主动粘贴分享文字、B 站链接及 BV/av；识别后确认打开。
- Android 系统分享面板可选择 Pili--，接收 `text/plain` 分享。隐私设置中的接收开关默认开启。
- 隐私设置中的自动剪贴板识别默认关闭；开启后进入前台读取。同内容提示会去重，关闭后不再自动读取。手动粘贴按钮是单次主动操作。

## 编辑首页和「我的」右上角按钮

打开「设置 → 外观设置 → 右上角按钮」，在「首页」或「我的」标签下勾选要直接显示的工具，拖动右侧手柄排序。「恢复默认」只影响当前页。从 0.6.3+12 起，所有可用工具均已勾选且能排下时，顶栏会用满可用位置。有工具收起或放不下时，点「⋮」即可打开。

「我的」默认把扫一扫和识别链接收在「更多操作」中。常用扫码时，可在「我的」的编辑页将它放回右上角。

## 动态页的 UP 主列表

从 0.6.2 起，新安装和从旧版本升级时，Live 和关注的 UP 主默认横排在动态分类下方。左右滑动选择 UP 主，点「全部动态」恢复完整时间线。需要侧栏时可在「设置 → 外观设置 → 动态页UP主显示位置」重新选择。

## 0.6.0 悬浮导航

入口为“设置 → 外观设置 → 悬浮底栏”，开关即时生效。0.6.0 默认启用；如果此前明确关闭过，会保留关闭偏好。默认仍显示首页、动态、我的，导航项目的隐藏和顺序由“导航栏编辑”控制。

直接点击导航项即可切页；按住拖动时，选中背景跟随手指移动，停稳约 200 毫秒后才切到目标页。快速划过、停留不足就松手、拖出底栏或取消手势均撤销待切换；已切换后可继续拖向其他项。横屏和平板继续使用原有侧栏。具体交互、设计参考和验收边界见 [悬浮导航说明](FLOATING_NAVIGATION.md)。这些行为属于 0.6.0，0.5.0 下载包不包含本次改动。

## 从旧版升级

0.4.0 移除会员购与 UP 主页小店，默认导航恢复为首页、动态、我的。旧导航里的已删除项目会被忽略，保留有效项目的顺序与隐藏状态；若原来只保留了已删除项目，则恢复默认导航。

启动时清理旧商品收藏、浏览足迹及相关开关，不再打开对应存储。视频收藏、播放历史、账号与下载记录不受这项清理影响。使用旧版商店作为启动页时会安全回退到可用页面。

## 签名与覆盖升级

稳定渠道保留安装包名 `io.github.ktclat.piliminus`，使用同一张发行证书，并随版本提高 Android 构建号。每次使用最新稳定版的同架构 APK 覆盖安装即可保留数据。首次发布稳定版后可长期收藏同一个入口。[最新稳定版](https://github.com/Ktclat/Pili--/releases/latest)

从 **0.6.3+11** 起，在应用内点「下载更新」时，应用读取相应稳定版的 `BUILD_INFO.json`，核对包名、签名指纹、兼容架构与构建号后打开对应 APK。遇到发布信息缺失或网络异常，可重试或打开该版本的发布页核对。下载完成后由 Android 系统验证安装包并确认安装。

在 Actions 中，`Pili--Android-release-signed` 是使用维护者固定证书的安装包；`Pili--Android-test-signed` 是本次运行的临时测试包。需要长期覆盖升级时，请选稳定 Release，或从同一证书的发行签名附件下载。

### 旧测试签名迁移

v0.5.0-beta.1 和 v0.6.0-beta.1 使用不同的测试证书。若测试包和目标 APK 的签名不同，Android 会拒绝覆盖安装。可以继续使用旧版。如果决定更换签名，先在旧 Pili-- 中完成导出。

1. 打开「设置 → 关于 → 导入/导出所有数据 → 导出到压缩包」，将 ZIP 保存到自己可访问的「下载」或文档目录。用系统文件管理器确认文件存在并能打开。ZIP 包含设置、登录资料、黑名单和搜索记录，还可能含已记录的评论和自定义字体。请自行保管，账号会话过期时需要重新登录。
2. 只想迁移设置时，在「设置 → 关于 → 导入/导出设置」选「导出文件至本地」，保存设置 JSON，新安装后重新登录。离线视频、音频和下载任务需要单独处理。卸载前请记录仍要观看的内容，以便在新安装中重新下载。
3. 确认备份可用并决定更换后，卸载旧 **Pili--** 并安装目标 APK。上游 **PiliPlus** 使用独立包名，可以继续保留。
4. 在新安装的「设置 → 关于」打开原来的导入/导出项。ZIP 选「从压缩包导入」，设置 JSON 选「从本地文件导入」。导入会覆盖对应的本地数据。阅读应用的导入结果，重启后核对账号与设置。

预发布包仍需 ARM64 真机及真实账号网页／TV 授权验收；已执行与未执行的范围见 [验证记录](VALIDATION.md)。反馈请附应用版本/提交、下载的 Release 或 Actions 链接、设备型号与 Android 版本。
